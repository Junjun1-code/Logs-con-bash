# Logs-con-bash

Creado para maquina de Kali Linux-2026.

|| Crea una carpeta y dentro de esta se almacenan registros de: ||
- IP actual(es) del sistema.
- Usuarios conectados y registrados con su ultimo inicio de sesión en el sistema.
- Fallos en auth.log, agrupados por tipo de fallo.
- Sesiones exitosas en base a auth.log
